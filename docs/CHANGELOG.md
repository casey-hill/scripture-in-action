# Changelog

## 2026-11-05 - Milestone B

- Added schema version 1 / content version 1.0.0 with stable passage, translation,
  lesson, and journey IDs; day/order is journey-specific.
- Added six original wisdom lessons and a seventh synthesis/review lesson,
  with contextual notes, scenarios, three nuanced responses per lesson,
  practical takeaways, and private reflection prompts.
- Replaced Home placeholders with a seven-day outline and Challenge with the
  lesson reader, deep links, native keyboard-operable choices, live feedback,
  and back/next/Home navigation.
- Preserved themes, responsive touch targets, Pages base path, installability,
  prompt-based service-worker updates, and offline shell. Original lessons now
  work offline; cache status also recognizes an existing controlling worker on reload.
- Added labeled NIV and surrounding-passage links. No NIV Bible text is bundled,
  and offline NIV memorization remains blocked pending permission/licensing.
  Research basis and source limitations are documented in README.
- Progress remains a preview. No scores, saved responses, completion tracking,
  memorization games, scheduler, database, groups, or cloud features were added.
- Expanded curriculum-integrity and browser coverage. Physical tablet review is
  manual; this entry is not a deployment or pastoral-approval record.
